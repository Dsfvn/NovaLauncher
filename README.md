# NovaLauncher

An independent desktop launcher for Minecraft: Java Edition.

## Overview

NovaLauncher is a desktop application designed to make managing and launching Minecraft Java Edition simple and convenient.

## Features

* Microsoft account authentication.
* Minecraft Java Edition ownership verification.
* Minecraft version and installation management.
* Configurable RAM allocation and game resolution.
* Secure desktop architecture using Electron.

## Authentication

NovaLauncher uses Microsoft Authentication Library (MSAL) with the system browser and OAuth 2.0 authorization code flow with PKCE.

Successful authentication requires Microsoft, Xbox, and Minecraft Services validation. Users must own Minecraft: Java Edition to play.

## Project Status

NovaLauncher is currently under development. Integration with Minecraft Services is subject to the required application approval.
